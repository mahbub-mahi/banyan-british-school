# 🏫 Banyan British School Website

A modern, responsive school website built with **Next.js** and **Tailwind CSS**, designed to provide a clean and professional digital presence for an educational institution.

---

## 🌐 Live Demo
>  https://banyan-british-school.vercel.app/

---

## 📌 Overview

This project is a real-world frontend website built for Banyan British School.  
It focuses on delivering a modern, responsive, and user-friendly experience for students, parents, and visitors.

The design follows a **modern startup-style UI approach** while maintaining a formal educational identity.

---

## ✨ Key Features

- 🏠 Modern homepage with hero section
- 📖 About section highlighting school mission
- 📚 Programs / classes structure (Playgroup, Nursery, Primary)
- 👨‍🏫 Faculty showcase section
- 🖼️ Image gallery for school activities
- 📞 Contact form UI for inquiries
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎨 Clean and minimal UI design
- ⚡ Fast performance with Next.js

---

## 🛠️ Tech Stack

- Next.js (App Router)
- React.js
- Tailwind CSS
- JavaScript (ES6+)
- Framer Motion (optional animations)
